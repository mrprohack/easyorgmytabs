# Privacy Policy

Easy Organize My Tabs processes browser tab metadata locally inside the extension.

## Data used

The extension reads open-tab titles, URLs, window identifiers, pin state, mute state, and favicons so it can display and manage tabs. Saved sessions and preferences are stored in `chrome.storage.local` on the user's browser profile.

## Data not collected

The extension does not include analytics, advertising, telemetry, remote code, user accounts, or external API calls. It does not sell, share, or transmit browser data.

## Permissions

- `tabs` enables tab listing and tab-management actions.
- `storage` saves local settings and sessions.

No host permissions are requested.

## Deleting data

Saved sessions can be deleted from the options page. Removing the extension deletes its local extension storage according to browser behavior.
